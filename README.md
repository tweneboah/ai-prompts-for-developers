## ✍️ Writing

### Article Outline Generator
```
Create a detailed outline for a [topic] article targeting [audience].
Include main sections, key points under each section, and estimated word count.
```

### Email Subject Line Creator
```
Generate 5 compelling email subject lines for [email_purpose].
Each should be under 50 characters and create urgency or curiosity.
```

### Blog Post Editor
```
Review this blog post for clarity, tone, and SEO optimization:
[paste your blog post]
Provide specific suggestions for improvement.
```

## 💻 Coding

### Code Debugger
```
Debug this code and explain what's wrong:
[paste your code]
Provide a corrected version and explain the issue.
```

### Function Explainer
```
Explain this function in simple terms:
[paste your code]
Break down each part and explain what it does.
```

### Code Review
```
Review this code for best practices, performance, and security:
[paste your code]
Suggest improvements and potential issues.
```

## 📢 Marketing

### Product Description
```
Write a compelling product description for [product_name].
Target audience: [describe your audience]
Key features: [list key features]
Tone: [professional/casual/playful]
```

### Social Media Posts
```
Create 3 engaging social media posts about [topic] for [platform].
Include relevant hashtags and emojis.
Keep them under [character limit].
```

### Campaign Idea Generator
```
Brainstorm 5 creative marketing campaign ideas for [product/service].
Each should include a catchy name, main message, and target audience.
```

## 💼 Business

### SWOT Analysis
```
Conduct a SWOT analysis for [company/product]:
- Strengths
- Weaknesses
- Opportunities
- Threats
```

### Business Plan Outline
```
Create a business plan outline for [business_idea].
Include sections on market analysis, competition, financial projections, etc.
```

### Competitor Analysis
```
Analyze [competitor_name] as a competitor to [your_business].
Compare pricing, features, marketing strategy, and customer reviews.
```

## 🎬 Content Creation

### YouTube Video Title Generator
```
Generate 5 catchy YouTube video titles for a [video_topic] video.
Make them attention-grabbing and include relevant keywords.
Titles should be under 60 characters and create curiosity.
```

### YouTube Description Writer
```
Write an engaging YouTube video description for:
Title: [video title]
Topic: [topic]
Duration: [length]
Include timestamps, links, and clear call-to-action.
```

### Udemy Course Outline
```
Create a detailed course outline for a Udemy course on [subject].
Include:
- Course title and description
- Learning objectives
- Number of sections and lessons
- Key topics per section
```

### Udemy Course Description
```
Write a compelling Udemy course description for [course_topic].
Include benefits, target audience, prerequisites, and what students will learn.
Make it persuasive and clear about the value proposition.
```

### Video Script Outline
```
Create a script outline for a [length]-minute video about [topic].
Include:
- Hook (first 30 seconds)
- Main sections with key points
- Examples or demonstrations
- Call-to-action (ending)
```

### Podcast Episode Title
```
Generate 10 compelling podcast episode titles for an episode about [topic].
Make them intriguing and include keywords for discoverability.
```

### Content Series Ideas
```
Brainstorm a [number]-video series or [number]-course bundle about [subject].
Include episode/lesson titles, key takeaways, and progression.
```

### Thumbnail/Thumbnail Concept
```
Describe 3 compelling YouTube thumbnail concepts for a video titled "[video_title]".
Include visual elements, text, color schemes, and why they'll catch attention.
```

## 🚀 Getting Started

1. **Browse the prompts** above or in the category folders
2. **Copy a prompt** that matches your needs
3. **Customize it** with your specific details
4. **Share with your users** so they can get better AI results

## 💡 Tips for Better Results

- Be **specific** - Include details about your target audience, tone, and desired output
- Use **examples** - Show the AI what format you want
- **Iterate** - Refine prompts based on results
- **Experiment** - Try different phrasings to improve outputs
